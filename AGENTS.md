# Organization policy repository

Maintain LANGUAGE_POLICY.md and CONTRIBUTING.md in English. The organization
uses English as the default for product and library surfaces, documentation,
examples, accessible labels and release notes. Honor explicit localization and
preserve source-data language. See LANGUAGE_POLICY.md for scope and rollout
boundaries. This file's automatic filesystem scope is this repository; other
repositories should reference the organization policy in their own guidance.

Use [TERMINOLOGY_POLICY.md](TERMINOLOGY_POLICY.md) for Mithril-authored Super
Intelligence (SI) copy. Preserve third-party names, source evidence and technical
identifiers; public Web and current documentation have rollout priority.
