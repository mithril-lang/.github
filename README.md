# Mithril organization defaults

[Language policy](LANGUAGE_POLICY.md): English is the default across the
`mithril-lang` organization; explicit localization and source-data languages are
preserved.

[Intelligence terminology](TERMINOLOGY_POLICY.md): use Super Intelligence (SI)
in current Mithril-authored copy, preserving third-party names, evidence and
technical interfaces. Public Web and documentation have rollout priority.

[Default contribution guide](CONTRIBUTING.md) applies through GitHub community
health defaults where a repository does not define its own guide. Existing
runtime defaults are changed and verified in each consuming repository.
